# petXpert Web

Promotional website for **petXpert**, a pet equipment store in Guatemala that sells professional grooming and veterinary supplies, ships to all 22 departments, and repairs dryers, drills and clippers.

The site is in Spanish and is built with plain HTML, CSS and JavaScript, with no build step.

## Pages

| Page | Content |
| --- | --- |
| `index.html` | Home: hero, stats, sections overview, brands (MGT, Andis, Purple Dragon, Wahl, Bio-Groom) and contact |
| `productos.html` | Products: cards expand to show a description and link to WhatsApp |
| `reparacion.html` | Repair service |

## Features

- Responsive layout with a mobile menu
- Scroll reveal animations and animated counters
- Brand marquee
- WhatsApp and click-to-call contact links
- SEO metadata, Open Graph tags and schema.org `Store` data

## Running locally

Open `index.html` in a browser, or serve the folder with any static server:

```bash
npx serve .
```
