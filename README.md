# Portfolio

A collection of my web projects. Each project lives in its own folder.

| Project | Description | Tech | Live |
| --- | --- | --- | --- |
| [petxpert-web](petxpert-web/) | Promotional website for petXpert, a pet grooming and veterinary equipment store in Guatemala | HTML, CSS, JavaScript | [View site](https://sebasgalin.github.io/portfolio/petxpert-web/) |
| [Brick Breaker Game basic](brick-breaker-game-basic/) | Classic brick breaker game with power-ups, ball spin and lives | Python, pygame | Desktop game ([how to run](brick-breaker-game-basic/README.md#running-the-game)) |

## Adding a project

1. Create a new folder at the root of this repo, for example `my-next-project/`.
2. Add a `README.md` inside it describing the project.
3. Add a row to the table above.
